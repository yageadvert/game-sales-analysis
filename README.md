# Предобработка данных датасета о продажах игр
Учебный проект по предобработке и первичному анализу данных о продажах видеоигр.\
В ходе работы данные очищены, типы приведены к оптимальным, пропуски и дубликаты обработаны, а также сформирован датафрейм с актуальными играми для дальнейшего анализа.\
Проект может быть основой для дальнейшего анализа популярности жанров, платформ и факторов, влияющих на продажи игр.

## Цели и задачи проекта
Провести предобработку и нормализацию данных о продажах игр разных жанров и платформ с пользовательскими и экспертными оценками.


## Данные
В проекте использованы данные датасета `new_games.csv`.
Датасет содержит 11 столбцов и 16,956 строк с таким описанием:
- `Name` — название игры.
- `Platform` — название платформы.
- `Year of Release` — год выпуска игры.
- `Genre` — жанр игры.
- `NA sales` — продажи в Северной Америке (в миллионах проданных копий).
- `EU sales` — продажи в Европе (в миллионах проданных копий).
- `JP sales` — продажи в Японии (в миллионах проданных копий).
- `Other sales` — продажи в других странах (в миллионах проданных копий).
- `Critic Score` — оценка критиков (от 0 до 100).
- `User Score` — оценка пользователей (от 0 до 10).
- `Rating` — рейтинг организации ESRB (англ. Entertainment Software Rating Board). Эта ассоциация определяет рейтинг компьютерных игр и присваивает им подходящую возрастную категорию.

## Ключевые результаты
- Названия столбцов датасета были переименованы в соответствии со стилем snake case;
- Для оптимизации памяти у двух столбцов уменьшена разрядность числовых типов данных;
- Пропуски в продажах заменены средними значениями по платформе и году выпуска игры;
- Пропуски в оценках игры заменены на метки -1;
- Строки с критическими пропусками удалены;
- Всего найдено и удалено 476 строк дубликатов названий игр;
- Для детального анализа по заданным требованиям с фильтром по годам с 2000 по 2013 год был создан новый датафрейм `df_actual` на 12776 строк.

## Итоговые выводы
- Всего очищено и удалено 517 строк.
- Среди игр, выпущенных с 2000 по 2013 год:
  - 49% игр не имеют пользовательской оценки;
  - 32% игр получили среднюю пользовательскую оценку;
  - 18% - высокую;
- По оценкам критиков:
  - 44% игр не имеют оценки критиков;
  - 42% игр получили среднюю оценку критиков;
  - 13% игр - высокую;
- За этот период больше всего игр вышло на платформе PS2 - 2,126 игр, на втором месте DS - 2,120 игр.
